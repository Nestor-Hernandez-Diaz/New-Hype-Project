Introducción

NEW-HYPE es un sistema de planificación de recursos empresariales (ERP) diseñado específicamente para tiendas de ropa y negocios del sector comercio minorista, su arquitectura multi-tenant (Multi-Negocios) permite que múltiples sucursales operen de forma independiente bajo una misma plataforma, optimizando la gestión de inventarios, ventas, clientes y operaciones administrativas.

La presente documentación describe de manera detallada todos los endpoints disponibles en la API REST de NEW-HYPE, construida con Spring Boot La API está organizada en cuatro entornos principales: Negocios (administración por sucursal), StoreFront (tienda online), Superadmin (gestión de planes y negocios) y Autenticación (gestión de tokens y accesos).

Cada endpoint incluye información sobre sus parámetros de entrada, cuerpo de la solicitud (request body), formato de respuesta y ejemplos prácticos en formato JSON, Navegue por el menú lateral para explorar los módulos disponibles o utilice el buscador para localizar endpoints específicos.

Base URL

Todas las peticiones a la API deben realizarse utilizando la siguiente URL base. Cada endpoint documentado muestra su ruta relativa, la cual debe concatenarse a esta URL.

http://spring.informaticapp.com:5001/New-Hype-Project

Autenticación

La mayoría de los endpoints requieren autenticación mediante un Bearer Token (JWT). Este token debe incluirse en el header Authorization de cada petición protegida:

Authorization: Bearer <tu_access_token>

Obtener Token de Acceso

Para probar los endpoints protegidos, primero necesitas obtener un token de acceso. Puedes generar uno rápidamente desde la página de registro de la plataforma:
